# Materials and lightmaps

Sources: static analysis of `gfx_d3d_x86_s.dll` (v1.0) with REA 6.7.0 + Ghidra 12.1.4, checked against the
shipped `materials/*` files and the game's own shader sources (`materials/shaders/lib/*.hlsl`).

## Material file (`materials/<name>`, binary, little endian)

Loaded through `materials/%s` (`FUN_1001c7a0`) and fixed up in `FUN_1001c540`.
Every offset field is relative to the start of the file and is turned into a pointer at load time.

| Offset | Type | Field | Status |
|---|---|---|---|
| 0x00 | uint32 | offset of material name | observed (relocated) |
| 0x04 | uint32 | offset of a second name (the reference image; equals the colorMap image in the samples) | relocated; meaning inferred |
| 0x08–0x2b | – | sort key and other flags | mostly not decoded; **byte 0x0d = draw sort byte** (1.3 DLL: the loader copies the 0x44-byte header verbatim, 0x100171a0, and nothing rewrites it; the table sort 0x10016ae0 orders by it ascending, then by techset allocation address = techset first-load order, 0x1001c280 allocates 0x8c bytes per techset; shipped values: 3 default/opaque (2120 files), 4 sky, 5 sun, 7 backdrops, 8-16 decals, 19-23 alpha, 25-26 effect blends, 27 additive (518), 28); byte 0x0c: bit 8 sky (1.0 DLL FUN_10002a00), bit 4 no marks (1.3 DLL FUN_100157f0); bytes 0x0e / 0x0f: atlas rows / columns (0x10017580, 0x1003fa60) |
| 0x2c | uint32 | state bits word 0 (blend: mtlDestBlend 0xf0, mtlBlendOpAlpha 0x7000000, mtlSrcBlendAlpha 0xf0000, mtlDestBlendAlpha 0xf00000, mtlCullFace 0xc000, colour write 0x8000000 / 0x10000000, mtlFog 0x20000000) | statemap variable table 1.3 DLL 0x1018fd80 |
| 0x30 | uint32 | state bits word 1 (mtlDepthTest 0xe, mtlDepthWrite 0x1, mtlPolygonOffset 0x30, mtlStencil 0xc0, stencil func / ops 0xe0000 / 0x700 / 0x3800 / 0x1c000) | same table |
| 0x34 | uint16 | texture count | observed (loop bound) |
| 0x36 | uint16 | constant count | observed (loop bound) |
| 0x38 | uint32 | offset of technique-set name (`materials/techniquesets/<name>.techset`) | observed |
| 0x3c | uint32 | offset of the texture table | observed (relocated) |
| 0x40 | uint32 | offset of the constant table | observed (relocated) |

Texture entry (12 bytes):

| Offset | Type | Field |
|---|---|---|
| 0 | uint32 | offset of the sampler name (`colorMap`, `detailMap`, `normalMap`, `specularMap`, …), hashed at load time |
| 4 | uint8 | sampler state (inferred) |
| 5 | uint8 | semantic: 2 = color (also used by `detailMap`), 3 = normal, 4 = specular, 5 = water. These values are compared in the loader; the names come from the data |
| 6 | uint16 | padding (always 0 in samples) |
| 8 | uint32 | offset of the image name (`images/<name>.iwi`). For semantic 5 it is an offset to a water description instead |

Images whose name starts with `$` are built-in (generated by the engine, for example `$white`).

Constant entry (20 bytes): `uint32 nameOffset; float value[4]` (for example `detailScale = 8 8 0 0`).

## Lightmaps (lump 1 of `.d3dbsp`)

Each 4 MiB lightmap holds four images back to back. Their sizes come from `FUN_10001ff0`:

| Part | Size | Bytes/px | Shader sampler (from `globals.hlsl`, `lightmap.hlsl`) |
|---|---|---|---|
| 0 | 512 × 512 | 4 (B,G,R,A) | `lightmapSamplerR`: 4 lighting coefficients for red |
| 1 | 512 × 512 | 4 | `lightmapSamplerG` |
| 2 | 512 × 512 | 4 | `lightmapSamplerB` |
| 3 | 1024 × 1024 | 1 | `lightmapSamplerSun`: sun visibility |

The game's shader computes `lightmapDiffuse.c = dot(coeffs_c, weights)`. Here `weights` is sampled from the
engine-generated `$lightmapweights` texture at the normal-map sample. Sun light is then added as
`sunVisibility × lightColor0 × max(0, N·L)` (`lightmap.hlsl`, `phong.hlsl`).

### `$lightmapweights` (32 × 32, ARGB8888), built in `FUN_1000fef0` and `FUN_1000fdd0`

For texel `(i, j)`: `x = 2(i + 0.5)/32 − 1`, `y = 2(j + 0.5)/32 − 1`. If `x² + y² > 1`, the vector is normalized.
`z = sqrt(1 − x² − y²)`. The four weights, stored as bytes 0..3 of each texel (`round(w × 255)`), are:

1. `t = atan2(y, x) × 3/(2π) − 0.75`, wrapped into `[0, 3)`.
2. `t ∈ [0,1)`: `(w1, w2, w3) = (1 − t, t, 0)`. `t ∈ [1,2)`: `(0, 2 − t, t − 1)`. `t ∈ [2,3)`: `(t − 2, 0, 3 − t)`.
3. `w0 = clamp(1 − angle(z) × 1.0467734, 0, 1)`. The angle function (`FUN_100f8d90`) is inferred to be `acos`;
   the constant is `1 / acos(1/√3)`.
4. `w1..w3 *= (1 − w0)`.

So a flat normal map gives weights `(1, 0, 0, 0)`: only byte 0 of each coefficient texel is used. The renderer must
keep the same byte order for coefficient and weight textures.

Sun direction: the forward vector of the worldspawn `sundirection` angles (pitch, yaw, roll) points **towards** the sun.
With this convention the lightmap sun-visibility shadows line up with the sun-lit faces (checked visually on `toujane`).

When `r_optimizeLightmaps` is 2, the renderer instead merges the lightmaps into one RGBA image per lightmap,
built from part 0.

Lightmap index 31 on a triangle soup means "no lightmap".

## Polygon offset (1.3 DLL 0x1003d230)

mtlPolygonOffset values "0" / "1" / "2" = 0 / 0x10 / 0x20 (value list 0x1018fab8); the statemaps pass it through.
When the level changes: D3DRS_SLOPESCALEDEPTHBIAS (0xaf) = level · r_polygonOffsetScale and D3DRS_DEPTHBIAS (0xc3) =
level · r_polygonOffsetBias · 2⁻¹⁶ (0x1019be30); without slope-scale support only DEPTHBIAS, doubled. Dvars
(0x1000adaa / 0x1000adce): r_polygonOffsetScale default −1 (−4..4), r_polygonOffsetBias default −1 (−16..16).
iw2view: offset pipelines with the slope factor and the constant added to the clip depth in `vs_main`.

## Face culling (1.3 DLL 0x1003cb13)

mtlCullFace = bits 14–15 of state word 0 (file 0x2c, mask 0xc000; values None / Back / Front = 0x4000 / 0x8000 /
0xc000, table 0x1018fa10); D3DRS_CULLMODE from {0, D3DCULL_NONE, D3DCULL_CCW, D3DCULL_CW} (0x10190704), i.e. Back
culls counter-clockwise (back) faces with D3D's clockwise front faces. 371 of the shipped materials sampled use Back.
iw2view: pipelines per pass × polygon offset × cull, front face clockwise (the opposite winding renders the toujane
houses inside out). TODO(spec): the mark draw path (0x10024320) keeps no culling.
